# Learner-request discovery upgrade — October 4, 2026

This release makes the existing learning-design methods discoverable for the
demonstrated explorable teaching requests. It preserves all 77 skill entrypoints
and the conditional comparison, experience-mapping and support-transition
methods delivered earlier in this milestone. It does not finish the source quarry.

## What changes

A bounded learner-model profile requires five independent cue families:
teaching purpose, requested preparation/teaching action, explanatory objective,
an explorable representation, and manipulation or feedback. Meaning-bearing
owner metadata must also match; there is no skill-ID or exact-query lookup.

Ordinary manipulable classroom materials are recognized. Nominal mentions of
training do not supply a request verb. The declared “rather than” refusal stays
intact through clause segmentation instead of manufacturing a positive request.

A fully corroborated teaching request has a separate ordering tier before
incidental keyword hits. Existing weighted scores and the capped 60-point intent
component are unchanged. Within a tier, score and stable ID order still apply;
scores need not descend between tiers. The README and returned reason disclose
this. Other intent profiles retain their prior ordering. Host no-need, category,
task and anti-trigger exclusions still run before ranking. No skill is selected,
activated or authorized by discovery.

Exactly three runtime payloads change: `README.md`, `lib/discovery.mjs`, and
`lib/product.mjs`. The other 254 payloads, catalog bytes, 77 metadata/scoring
projections, existing methods and protected activation artifacts are unchanged.

## Negative evidence and limits

The failed v1-v4 candidates and receipts remain immutable. V2 and v3 each passed
11/28 fixed cases; v4 passed 28/28 disclosed regressions but only 5/7 then-fresh
follow-ups. Those two misses and the separate refusal finding caused this
versioned repair. All 37 cases are now revealed regressions: this final result
is replication, not virgin held-out accuracy, a universal semantic classifier
or evidence of real learner efficacy.

These finite English rules do not solve arbitrary negation, nested quotations,
multilingual discourse, future/mixed scope or unseen false positives. The agent
still checks the actual task and reads only relevant methods. This was not a
fresh-OS or fresh-chat enumeration test, raw-agent superiority trial, source
rights clearance, automatic invocation or empirical outcome study.

The frozen R10 ledger remains 49,514 open identity obligations and 163 conflicts.
No source disposition was applied. Equal source bytes never transfer rights,
provenance or terminal outcomes. The current milestone ends after the separate
backed-up installation audit; no new acquisition or refinement arc follows.
