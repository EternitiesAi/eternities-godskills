# Whole current-pack refinement — October 4, 2026

## Scope and result

This milestone refines the complete 77-entrypoint portable Godskills product,
not one skill and not the unresolved acquired-source quarry. The starting main
commit is `dc704536875cda166f7ab784bce28f3c2b54ae0c`, shipping release
`b3939c86a82ad58d6111942aa431c61a7b3eae173409f3e5b79e053916aad5f1`.

Every entrypoint has an explicit identity-bound assessment: 42 targeted
refinements and 35 deliberate retentions. See the [39-skill assessment](refinement-20261004/cohort-A-assessment.json)
and [repaired 38-skill assessment](refinement-20261004/cohort-B-assessment-v2.json). The
[first B assessment](refinement-20261004/cohort-B-assessment.json) remains historical. Each
records retained mechanisms, reasons, exact baseline/candidate entrypoint hashes,
and direct, paraphrase, exclusion and boundary case proposals. Those 308 proposed
cases are not 308 executed tests or measured outcomes.

## What changed

- Narrow tasks reuse settled decisions rather than manufacturing a full design,
  audit, recruitment, release or coordination packet. Delivery closes against
  the requested artifact, not a plan or a handoff when implementation is required.
- Specialist processing branches remain distinct: terrain derivatives versus
  drainage versus visibility; candidate evaluation versus funnel diagnosis;
  existing study observations versus planning new recruitment; descriptive versus
  causal scientific appraisal.
- Concrete checks were clarified, including server minimum retry waits,
  destination-reference allele validation after coordinate mapping, full declared
  infrastructure dependency/state context, defect-relevant robot test tiers and
  bitwise versus predeclared numerical replay.
- Existing strong methods were retained rather than rewritten for a word-count
  target or because a newer model was available. Voice fidelity, imaginative
  causal alternatives, memory/effect reconciliation, workbook integrity, source
  lineage and other non-obvious mechanisms remain part of the product.
- The [portable guide](../product/README.md) explains proportionate depth and
  composition. Detailed finite retrieval and eligibility limitations moved into
  [optional discovery documentation](../product/DISCOVERY.md), not into an
  always-loaded workflow. Search scores, ranking, profiles and authority behavior
  are unchanged.
- Real builder fixtures now reject ambiguous or unsupported native name and
  description forms. The inspector intentionally implements a conservative
  metadata subset, not general YAML or arbitrary optional-metadata validation.

## Preservation and honest resource limits

All IDs, skill metadata, invocation policies, declared resources and historical
method-review identities are preserved. Existing non-entrypoint skill files and
protected activation bytes must remain exact through integration.

Entrypoint text changed from 40,724 to 41,805 whitespace-delimited words. This is
a 1,081-word net increase, not a measured token reduction. The reason for added
text is corrected task branching or domain checks. The library remains lazy:
agents inspect compact metadata and read the selected complete entrypoint plus
only the relevant reference. No token, cache, latency or universal performance
improvement is claimed without a measured comparison.
