## Useful method, existing owner

The detailed [research-funding proposal procedure](../product/skills/eternities-agora/references/research-funding-proposal.md)
extends Agora's existing research-proposal route. It is loaded only when a named
funding opportunity needs detailed argument, workplan, resource or review work.
Ordinary prospect and account tasks do not load it. There are still 77
entrypoints, not an overlapping new research-proposal skill.

The procedure connects controlling documents and section locators to requirement
states, aims and interpretable outcomes, dependencies, workplan, resource
assumptions and review criteria. It distinguishes planned work from observed
results, access requests from commitments, estimates from approved budgets, and
local drafts from submission. No agency template, provider, renderer, account,
local directory or external service is required to use the method.
