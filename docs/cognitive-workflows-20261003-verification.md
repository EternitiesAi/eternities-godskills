# Cognitive and sustained-work methods: October 3, 2026

## Scope and current disposition

The approved expansion adds six portable methods to the existing 68-skill pack.
This expansion is completed, published and installed. All six methods are
instruction-reviewed and content-verified; the final corrected cases are
independently READY. Release implementation commit
`a21f38aae6dfe777795c8f3af9b984a463f57404` was fast-forwarded into main and pushed,
and remote main was independently queried to confirm that exact revision before
installation.
This is a finite product expansion, not a restart or closure of the source corpus.

| Method | Useful result |
| --- | --- |
| Voice-style calibration | An example-grounded writing profile and adapted draft that preserve current facts and caveats |
| Imaginative concept development | Materially different mechanisms or experiences, developed against the actual brief |
| Interpersonal understanding and dialogue | A grounded perspective map, clarification or respectful reply without invented motives |
| Memory retention and recovery | A minimal source-linked checkpoint, actual authorized persistence when available, and stale/conflict recovery |
| Completeness and consistency audit | An obligation map tracing actual content, contradictions, unknowns and coherent repairs |
| Long-horizon work continuity | Milestone ownership, compact handoffs and uncertain-effect reconciliation across interruption |

The pack remains optional, lazy-loaded guidance rather than a mandatory six-step
ritual. It does not provide clinical diagnosis, unlimited recall, a scheduler,
tools, provider authentication or permission to act. The host supplies those
facilities. Native host skills remain complementary, not copied dependencies.
See [HOST-CAPABILITIES](../product/HOST-CAPABILITIES.md) and the three new
[composition examples](../product/RECIPES.md).
