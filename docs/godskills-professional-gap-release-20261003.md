## Delivered methods

- **Structured hiring evaluation:** turn role outcomes into behaviorally anchored
  assessments, collect independent evaluator evidence, reconcile disagreements,
  and measure the recruiting flow with explicit cohorts and denominators.
- **Customer support triage and resolution:** distinguish symptoms, causes,
  policy-dependent severity, attempted troubleshooting, escalation, implementation,
  verification, and customer confirmation. Produce truthful replies without
  implying that messages were sent or fixes applied.
- **User research and usability study:** design decision-linked interviews or
  usability tasks, preserve observation versus interpretation, account for help
  and sampling, and connect findings to bounded changes without inventing
  participant evidence or population prevalence.

These are independently written methods informed by four exact source bodies
already present in the warehouse. [The source review](godskills-gap-refinement-20261003.md)
records revisions, body hashes, rejected assumptions, and scope. No new acquisition,
source execution, automatic third-party activation, or legal clearance is claimed.

## Discovery change

The real search and route callers now accept a host-owned need decision:

```console
node product/bin/godskills.mjs search "a short work-note rewrite" --need none
node product/bin/godskills.mjs search "structured hiring interview" --need specialist --limit 3
```

`none` returns no specialist candidates; `specialist` returns candidates requiring
fit review; the default `unknown` remains honest candidate retrieval. None of
these states authorizes a skill, connected source, message, or external action.
Omnibus now checks the intended action, expected benefit, and exclusions before
retrieving a workflow. Ordinary competence is a valid route.

This fixes the caller's inability to express no need; it is not a semantic
classifier. The underlying lexical ranker is unchanged and can still retrieve
irrelevant matches. Host-supplied decisions must not be presented as automatically
inferred routing accuracy, or as proof of improved agent performance.
