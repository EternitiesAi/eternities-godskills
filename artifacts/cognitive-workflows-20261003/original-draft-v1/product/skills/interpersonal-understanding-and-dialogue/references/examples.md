# Interpersonal dialogue examples

Read this reference when the evidence conflicts or a missing fact changes what a respectful reply should say.

## When two accounts differ on what was agreed

The notes contain a Monday message, “I can help Thursday,” and a Friday clarification, “I meant setup, not the full shift.” The task and hours were never written down.

- **Observed:** the first offer was broad; the later account limits it to setup.
- **Unknown:** the hours and exact task understood on Monday.
- **Not established:** dishonesty, indifference, or a refusal to help.

A useful reply could say: “I read ‘help Thursday’ as the full shift, but I may have assumed too much. I understand now that you meant setup. Which hours or tasks, if any, can you take? If setup is all that works, I’ll plan the remaining coverage.” It acknowledges the mismatch, asks for the missing detail, and leaves room to decline.

If the speaker already accused the person of breaking a promise, repair that action directly: “I called you unreliable before checking what we had agreed. That was unfair. I’m sorry. I’ll treat the full shift as unassigned unless we confirm it together.” Do not require reassurance or forgiveness to close the repair.

## When silence is being read as anger

The only evidence is that a reply has not arrived since yesterday; the message was not marked urgent and availability is unknown. “They are angry with me” is an interpretation, not an observation. If an answer is needed, ask about availability or timing without presenting anger as fact: “I’m checking whether you saw my note. Is there a time that works to discuss it? No rush if you’re unavailable.” If no action depends on a reply, waiting is also a valid option.
