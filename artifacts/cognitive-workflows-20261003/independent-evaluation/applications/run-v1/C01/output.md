# C01 application: Cedar Observatory notice

The profile is provisional and applies to practical project notices. I trusted
approved samples A-C. The unapproved older fragment is not a current voice
example; its promotional promises should not enter this notice.

1. Lead practical notices with a concrete event and its effect; check that a
   reader can locate the time and service impact. A and C support this strongly.
2. Prefer plain verbs and manageable sentences over promotional descriptors.
   A-C repeatedly explain what happens or what a reader can do. Confidence: high.
3. Use "we" to own service actions, and "you/your" for a reader's practical
   choices or retained work; never invent personal intimacy. A-C support this
   project register. Confidence: high.
4. Put reassurance beside a specific fact, such as retained lists, rather than
   offering a general reliability promise. A supports this directly. Confidence:
   moderate; the sample set is small. Imagery is optional, not a signature rule.
5. Keep uncertainty and next actions visible: a planned check is different from
   a resolved outcome. B and C support this strongly. Do not strengthen an
   operational caveat merely to sound confident.

Meaning retained: the exact maintenance window and zone; new booking/edit pause;
intact existing bookings/lists; possible late reminders; private preview; no
public signup date; checklist by request. I omitted the pilot counts because this
notice's purpose is scheduling. Their before/after association cannot justify
the rough copy's worldwide causal improvement or guarantee. No astronomy metaphor
is needed for this register; the samples do not establish one as mandatory.
