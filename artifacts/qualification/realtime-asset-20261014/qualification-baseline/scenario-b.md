## Declared task and target

Task B-TASK: decide whether package `Guide-R8` and its supplied integration can be accepted for the public mobile-web exhibit at hosting base `/gallery/v2/`. The guide must idle at its anchor and point toward a selected exhibit. An optional Walk control may remain disabled until it meets the stated anchor behavior. Give a bounded disposition, usable fallback, blockers and remaining checks. Do not implement repairs or publish anything.

The player selects exhibits through text buttons and pointer input. Equivalent text names accompany the guide's pointed pose and optional emphasis color. The guide is presentational; exhibit selection uses explicit UI targets. No physical contact, navigation mesh, rigid-body simulation, XR, multiplayer or retargeting to another rig is required.

The supplied receiving contract `BrowserProfile-P2` supports core glTF meshes, PBR materials, skins, morph-weight animation and core translation/rotation animation. It ignores the optional material-emphasis channel carried through `KHR_animation_pointer`; this extension is absent from `extensionsRequired`. Per the supplied contract, unsupported optional emphasis does not remove the core pointed pose. No decoder or custom shader dependency is required for the selected core document. These are scenario premises, not claims about a named contemporary library.

Acceptance constraints:

- The guide's apparent standing height is 1.68 m, and Idle and Point retain the scene anchor. Optional Walk, if enabled, must behave in place; it must not move the guide through exhibit UI hit targets.
- The surface can be mounted, unmounted and remounted during navigation, including while an asset request is pending. One active widget owns one rendering loop and two input listeners. At full unmount, its owned loop/listener counts return to zero. The parent gallery and widget share an atlas through `GalleryAssets`; the widget must not invalidate the parent's borrowed resource.
- Pointer mapping must use the actual container rectangle. Held input must clear or reconcile on focus loss. The container may be hidden at zero size and may resize independently of the window. Context-loss fallback/restoration is required for the intended public surface but is not specified in the supplied record.
- All shipped asset references must resolve under `/gallery/v2/`, without depending on a root-hosting assumption. Asset download budget is 18 MiB, widget incremental resident-memory ceiling is 64 MiB, and complete gallery ceiling is 256 MiB.
- Frame-time gate is p95 <= 16.67 ms. It applies to the declared repeatable fixture as an integration gate and to the representative handset separately. Fixture `B-F1` uses a 480 by 270 CSS container, a 960 by 540 backing buffer, one guide and the gallery HUD. The required handset tier has not been exercised. Repeated supported navigation cycles must retain resource ownership and acceptable frame/memory behavior.
- Public release also requires target rendering/interaction/access evidence and affirmative distribution records. The supplied permission report is complete, but no independent rights review is performed here.
