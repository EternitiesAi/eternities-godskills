# Choose the next practice item from the evidence

Use when a learner's recent response leaves more than one plausible explanation
and the facilitator must choose what to offer next. The learning owner already
provides contrasts, feedback, fresh attempts and transfer checks. This extension
makes the response-to-next-item decision explicit. Skip for a fixed worksheet
request without adaptive delivery, or for certification and automated learner
ranking. It needs no stored learner profile.

## Name the unresolved distinction

Bind one observable objective, the supplied response, the prompt and answer key,
and which optional cues were used. Verify the answer key and allow valid alternative
methods before calling the response an error. Keep response format and access
supports separate from the concept being checked. Silence or slow completion does
not identify a misconception.

Identify the smallest plausible competing explanations that imply different next
actions. For example, a correct answer may reflect the intended principle, a
surface shortcut or a revealed answer; an incorrect result may reflect a selection
error, an execution slip or an ambiguous item. These are task hypotheses, not
learner traits. If the supplied work already settles the question, teach or advance
directly rather than manufacturing another diagnostic.

Design one short probe on which the competing explanations predict different
observable work. Vary the feature that separates them while holding incidental
reading, arithmetic and presentation demands as steady as possible. Ask for a
reason, intermediate step or demonstration when a final answer alone would collide.
State the expected responses and the next action before delivering the probe.
If the probe would reveal the very choice being assessed, label the resulting
work supported and use a fresh item for the independent observation.

## Branch without turning practice into an interrogation

- If a concept-selection error is supported, use a contrast that exposes the
  deciding feature, then offer a fresh item using that distinction.
- If the principle is sound but execution fails, target that step; avoid repeating
  the entire conceptual explanation.
- If a cue produced success, offer another comparable item with help still
  available. Record whether help was used; success does not authorize withdrawing it.
- If work supports the distinction, try a changed context or combine it with a
  previously available skill when that fits the lesson. Change one important demand
  at a time if changing several would make the next failure uninterpretable.
- If the evidence still fits several explanations, say so, offer help or a different
  representation, and stop probing when the agreed time or learner preference calls
  for teaching, a break or closure. Do not force a diagnostic label to keep a sequence moving.

Give the learner the prompt and useful feedback, not a classification dossier.
One small branch card can contain the evidence, probe, response-to-action map,
and next item. If an optional aid change across sessions is actually requested,
use the owner's support-transition procedure; this method cannot replace its
learner choice, restore route or persistence boundaries. Protected supports remain.

## Worked decision

Fictional objective: compare fractions of the same whole. The learner correctly
chooses 5/8 over 3/8 and explains "five is bigger." This is compatible with both
fraction understanding and a numerator-only shortcut; it does not justify harder
arithmetic. Probe: "Which is greater, 3/5 or 3/8, for equal-sized wholes? Show or
explain why." The expected answer is 3/5 because three fifth-sized parts exceed
three eighth-sized parts of the same whole.

If the learner says they are equal because the numerators match, demonstrate equal
wholes partitioned differently, then offer 2/3 versus 2/7. If they select 3/8 because
eight is larger, use the same representation to examine part size, then offer that
fresh comparison. If they explain part size correctly, offer an unfamiliar same-whole
context using 4/9 versus 4/6. If the wording or presentation blocks access, change
that first and keep conceptual interpretation unresolved. Diagrams and help stay
available; label aided work accordingly. The expected fresh answers are 2/3 and
4/6 respectively. This example is a proposed branch design, not a learner result.

## Check the method as well as the learner

A tutor must accept an equivalent algebraic route: dividing every term on both
sides before subtracting can be valid. A mismatch with a preferred solution order
does not warrant corrective hints. Similarly, an explanation after the answer
was revealed does not establish independent performance. Finish with a usable next
item, its answer or rubric, the evidence-linked branch, help route and stopping
point. Later retention and improvement from adaptation remain unmeasured unless
separate authorized observations supply them.
