# Synthetic task-feed application v3 contract

This is a dependency-free local example using supplied in-memory callbacks. It is not a live-service client, production integration, durable-storage proof, or qualification of Hermes behavior.

The caller supplies task-bound authority, append-only/stable-ID/task-cursor declarations, explicit positive safe-integer page/event limits, a current checkpoint, `readPage({ taskId, after, limit })`, and atomic-commit callback `commit({ taskId, events: newUniqueEvents, cursor: nextCursor })`. Callback resolution is only the caller-declared adapter acknowledgment, not independent proof of persistence. No real credential validation or storage inspection occurs.

Fixture state is `{ cursor, events: [{ id, payload }] }`. Cursor tokens are opaque `null` or strings only; they are passed through exactly and never derived from event IDs. Events use nonempty string IDs and structured-cloneable fixture payloads. Every array position must be an own, valid event entry. A sparse hole or explicit invalid value returns `HOLD`: sparse/invalid saved state returns `HOLD/invalid-state` before either callback; a sparse/invalid returned page returns `HOLD/malformed-event` after that read, before commit, with the previous checkpoint preserved. Holes are rejected, never filled, compacted, or interpreted as events. Saved duplicate IDs remain rejected (both conflicting and equal payloads); the reader does not normalize history.

V2 behavior remains: caller-owned limits and drain guarantee are snapshotted before callbacks; validated page cursor/status/final-cursor values are snapshotted before commit; acknowledged state advances only to the exact cursor sent to commit; uncertain commit outcomes hold the prior acknowledged state and require reconciliation without retry or rollback claims. Empty running pages are idle; terminal without a declared final-cursor-equality guarantee remains unknown; terminal completion requires literal equality. Local stopping never cancels the remote task. Page/event caps do not impose a wall-clock bound on uncooperative callbacks. No percentage or ETA is produced.
